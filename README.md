# 신창의 모험 🛵 → 👑

배달원으로 시작해서 재벌이 되는 **안드로이드 방치형 클리커 게임**입니다.

## 밑그림 (게임 설계)

### 핵심 루프
```
탭(수동 클릭) / 오토클릭으로 돈 벌기
        ↓
아이템 구매·강화 → 오토클릭 속도 ↑
        ↓
마지막 아이템 + 전직 비용 → 다음 직업 (클릭당 금액 ↑↑)
        ↓
재벌 회장의 "글로벌 지주회사" 구매 → 엔딩
```

### 돈 버는 규칙
| 항목 | 규칙 |
|---|---|
| 직업 전환 | 한 번 도달한 직업은 위쪽 직업 버튼으로 언제든 돌아갈 수 있음 (전직은 가장 높은 직업에서만) |
| 오토클릭 모드 | 스위치로 ON/OFF |
| 방치 보상 | 앱을 꺼도 오토 수익의 50%가 최대 8시간까지 쌓임 |

### 1. 🛵 배달원: 클릭 1회 = 배달 1건 = 4,000원
탈것은 **오토 배달 속도만** 바꿉니다. 산 탈것은 겹치지 않고 **하나를 골라 타며**, 그래서 상위 탈것일수록 속도 가중치가 큽니다.
한 단계 오를 때마다 오토 배달 속도가 **거의 2배**라 탈것을 바꾸면 체감이 큽니다.
가진 탈것은 언제든 바꿔 탈 수 있고, **구매가의 70%에 되팔 수** 있습니다 (도보 제외). 팔아도 다음 탈것 해금은 유지됩니다.
가격은 국내 신차가 기준입니다.

비/눈이 오면 화면에 비·눈이 내리고 상단이 어두운 파랑으로 바뀝니다.

### 2. 🏠 공인중개사: 제한 시간 안에 목표 클릭 → 중개보수

보수는 법정 상한요율(주택 임대 0.3~0.6%, 매매 0.4~0.7%, 상가·빌딩 0.9%)로 계산하고 양쪽 당사자 몫을 합칩니다.

### ⛪ 교회 기부 (리셋 멀티플라이어)
가진 돈 전액을 교회에 기부하고 처음부터 다시 시작합니다. **이번 회차 총수입**에 따라 ⭐ 별을 받고,
별 1개당 모든 수입이 +10% (신의 축복) 됩니다. 별은 기부할 때마다 쌓입니다.
별 = (이번 회차 총수입 ÷ 1억)의 세제곱근

| 기부 시점 | 총수입 | 받는 별 | 수입 배수 |
|---|---|---|---|
| 배달 끝 | 2억 5,000만원 | 1개 | ×1.1 |
| 공인중개사 끝 | 100억원 | 4개 | ×1.4 |
| 소방기술사 끝 | 3조원 | 31개 | ×4.1 |
| 쇼핑몰 CEO 끝 | 300조원 | 144개 | ×15.4 |
| 엔딩 | 약 6,258조원 | 397개 | ×40.7 |

상단에 ⭐ 별 개수와 🙏 수입 배수(별 × 자기 투자)를 따로 표시합니다.
직업·아이템·탈것·계약 기록과 돈은 초기화되고, 별·신창에게 투자·해는 남습니다.

### ☀️ 완전 리셋
별과 신창에게 투자까지 모두 지우고 완전히 처음부터 시작합니다. **소지금**에 따라 ☀️ 해를 받습니다.
해 = (소지금 ÷ 1조)의 세제곱근. 해는 계속 남고, **해 1개당 모든 수입 +2% (영구)** 입니다.
최종 수입 배수 = 별 배수 × (1 + 자기 투자) × 해 배수

### 🏆 엔딩
재벌 회장의 글로벌 지주회사를 사면 엔딩 그림 3장이 차례로 나옵니다 (마지막 직업 카드에서 다시 보기).
👑 황제가 된 신창 · 🙌 칭송받는 신창 · 🏖️ 경제적 자유를 이룬 신창 (`tools/endings.py`로 생성)

### 🙏 종교계 (해 300개 이상)
경제적 자유를 이룬 신창은 종교에 귀의합니다. 종교계에서는 돈이 아니라 ✨ **영성 포인트**를 법니다.
화면이 금빛·흰빛의 성스러운 색으로 바뀌고 반짝임이 떠오릅니다. 세속(돈) 화면과 언제든 오갈 수 있고,
귀의한 뒤에는 어느 화면에 있든 자동 기도로 영성이 쌓입니다. 교회 기부·완전 리셋을 해도 종교계 진행은 남습니다.

탭(기도)과 자동 기도로 영성을 모아 직분을 올리고, 마지막 직분에 오르면 다음 종교로 옮깁니다.
**신천지로 옮길 때는 모든 영성 포인트를 잃고** 새로 시작하지만, 영성 획득이 직전 종교 최고 직분의 약 30배로 뛰어오릅니다.

| 단계 | 종교 | 영성 배수 | 직분 |
|---|---|---|---|
| 1 | ⛪ 일반 교회 | ×1 | 주일예배 → 세례교인 → 성가대 → 구역장 → 청년회장 → 전도사 → 강도사 → 목사 |
| 2 | ✝️ 구원파 | ×8 | 새신자 → 형제·자매 → 성경공부반 → 수련회 봉사 → 구역 모임 인도 → 전도인 → 전도집회 강사 → 목사 |
| 3 | 📖 안식일교회 | ×60 | 구도자 → 침례교인 → 안식일학교 교사 → 집사 → 장로 → 전도사 → 목사 → 합회장 → 연합회장 |
| 4 | 🗼 여호와의 증인 | ×450 | 성서 연구생 → 전도인 → 침례받은 전도인 → 보조 파이오니아 → 정규 파이오니아 → 봉사의 종 → 장로 → 여행하는 감독자 → 지부 위원 → 통치체 성원 |
| 5 | 🕊️ 하나님의 교회 | ×3,500 | 성도 → 집사 → 권사 → 장로 → 전도사 → 목사 → 당회장 → 총회장 |
| 6 | 🌟 신천지 | ×1,000만 | 교육생 → 성도 → 구역장 → 청년회장 → 교리 강사 → 전도사 → 교육장 → 지파장 → 총회 총무 |

**⭐ 교회에 별 기부하기**: 기부할 별 개수를 직접 적어서 내면 (100개 단위로 기부, 나머지는 남음) 100개당 **종교계 별 1개**가 쌓이고,
종교계 별 1개당 **영성 얻는 속도 +10%** (기도·자동 기도 모두). 남는 별은 그대로 두고, 기부한 별만큼 세속 수입 배수는 줄어듭니다.
종교계 별은 교회 기부·완전 리셋을 해도 남습니다. (세속 화면과 종교계 화면 모두에 버튼이 있습니다)

직분 이름은 공개된 보도와 일반적인 교회 직제를 참고한 게임 속 설정이며, 특정 종교나 단체를 평가하거나 홍보하지 않습니다.
초당 5번 탭하면 종교마다 약 20~40분, 마지막 직분까지 약 2시간 50분 걸립니다.

### 🏛️ 정계 진출 (종교계 이후)
신천지의 마지막 직분(총회 총무)에 오르면 정계에 진출합니다. 정계에서는 🗳️ **정치력**을 법니다.
탭(유세)과 지지자 활동(오토)으로 정치력을 모아 선거에 출마해 직위를 올립니다. 세속·종교계·정계는 언제든 오갈 수 있고,
진출한 뒤에는 어느 화면에 있든 정치력이 쌓입니다. 교회 기부·완전 리셋을 해도 정계 진행은 남습니다.

📋 정당 당원 → 지역 당협 청년위원 → 구의원 → 시의원 → 구청장 → 국회의원(초선) → 국회의원(3선) → 국회 상임위원장 → 광역시장 → 당 대표 → 국무총리 → 🇰🇷 대통령

**정치력 배수** = 💰 정치자금 × 🙏 종교계 인맥 × ☀️ 명성
| 배수 | 올리는 법 | 공식 |
|---|---|---|
| 💰 정치자금 | 세속에서 번 돈을 후원 (가진 돈의 1%/10%/50%/전액) | 1 + 0.25 × log10(1 + 후원금 ÷ 1억), 후원금 10배마다 +25% |
| 🙏 종교계 인맥 | 종교계에서 오른 직분 단계, 종교계 별 | 1 + 직분 단계 × 5% + 종교계 별 × 2% |
| ☀️ 명성 | 해, 세속 별 | 1 + 해 × 1% + (별 ÷ 100) × 1% |

| 상황 | 배수 | 대통령까지 (초당 5번 탭) |
|---|---|---|
| 막 진출 (후원 0, 종교계 인맥 최대, 해 300) | ×14 | 약 68분 |
| 후원 1경, 종교계 별 10, 해 300 | ×45 | 약 22분 |
| 후원 1해, 종교계 별 50, 해 1000 | ×200 | 약 5분 |

실제 정당·인물과 관계없는 게임 속 설정입니다.

### 🌀 환상의 세계 아르카디아 (대통령 이후, RPG)
대통령이 되면 「🌀 차원 이동 장치」 버튼이 생깁니다. 위에서 내려다보는 필드·마을·던전을 걸어 다니며
1:1 턴제 커맨드 전투(싸운다/주문/도구/방어/도망)로 성장하는 고전 판타지 RPG입니다. 이야기·캐릭터·몬스터는 모두 오리지널입니다.

**지금 들어 있는 이야기**: 프롤로그 「청와대의 머신」 + 1장 「배달부 용사」 (약 40분~1시간)
1. 청와대 집무실의 기계를 작동시키면 아르카디아 평원에 떨어진다
2. 리벨 마을 장로에게 예언과 「장로의 편지」를 받는다
3. 다리 건너 에르덴 성의 왕에게 편지를 전하면 견습 기사 **리나**가 동료가 된다
4. 북동쪽 그림자 동굴(2층)에서 **그림자 늑대왕**을 쓰러뜨린다
5. 왕에게 보고하면 1장 클리어 (2장 「상인의 길」은 다음 업데이트)

| 구분 | 내용 |
|---|---|
| 동료 | 신창(회복·불꽃 주문), 리나(강타·수호의 맹세) |
| 몬스터 | 들쥐 도적, 독버섯 꼬마, 박쥐날개, 가시늑대, 장난꾸러기 요정, 돌껍질 거북, 동굴 거미, 해골 병사, 그림자 늑대, 보스 그림자 늑대왕 |
| 주문 | 신창: 치유의 빛(Lv3), 불꽃(Lv5), 대치유(Lv8), **불꽃의 폭풍**(Lv9), **치유의 비**(Lv11), **짐꾼의 일격**(Lv13) / 리나: 강타(Lv4), **수호의 맹세**(Lv7, 받는 피해 절반), **기사의 연격**(Lv10) |
| 보스 | 그림자 늑대왕 = 수호 늑대 루프스. HP 절반에서 격노, 권장 Lv13~14 (`tools/BossSim.java`로 레벨별 승률 측정) |
| 레벨업 | 초반은 조금 느리고, 자기보다 강한 적을 쓰러뜨리면 경험치 보너스(레벨 차 1당 +25%, 최대 2.5배) |
| 장비 | 나무 막대 → 구리 검 → 철검 → 기사의 창 / 천 옷 → 가죽 갑옷 → 사슬 갑옷 → 은빛 갑옷(보물상자) |
| 마을 | 상점·여관(회복)·사제(기록), 전멸하면 골드 절반을 잃고 마지막 마을에서 다시 시작 |

**앞선 인생의 특기**: 배달 경험(몬스터를 덜 만남) · 공인중개사(상점 10% 할인) · 소방기술사(불꽃 +20%) · 종교계(회복 +30%)

**이야기 설계**: 전체 장 구성, 숨은 진실, 떡밥과 회수 계획은 [`docs/STORY.md`](docs/STORY.md)에 있습니다.
1장에는 책장·벽화·표지판·기록 상자 같은 **조사할 수 있는 물건**에 단서 5개가 숨어 있고, 메뉴 「📖 단서」에서 모아 볼 수 있습니다.
마을은 건물 안이 보이는 구조(가구, 계산대 너머 상인, 여관 침대, 성당 제단·벽화, 서고, 병영)로 `tools/rpg_maps.py`가 만듭니다.

자동 플레이 검사(`RpgPlay`)로 프롤로그부터 1장 클리어까지 막힘없이 진행되고, 모든 마을 사람에게 갈 수 있고, 단서 5개를 모두 모을 수 있는 것을 확인했습니다.
도트 그림은 `tools/rpg_art.py`로 생성합니다.

## 빌드 방법
**Android Studio**: 이 폴더를 열고 ▶ Run 을 누르면 폰/에뮬레이터에 바로 설치됩니다.

**명령어**:
```bash
./gradlew assembleDebug
# 결과물: app/build/outputs/apk/debug/app-debug.apk
```

**밸런스 시뮬레이션** (안드로이드 SDK 필요 없음):
```bash
javac -encoding UTF-8 -d out app/src/main/java/com/shinchang/adventure/game/*.java tools/Simulate.java
java -cp out Simulate 3     # 숫자 = 초당 탭 횟수
```
