# 신창의 모험 🛵 → 👑

배달원으로 시작해서 재벌이 되는 **안드로이드 방치형 클리커 게임**입니다.

## 밑그림 (게임 설계)

### 핵심 루프
```
탭(수동 클릭) / 오토클릭으로 돈 벌기
        ↓
아이템 구매·강화 → 오토클릭 속도 ↑
        ↓
마지막 아이템 + 전직 비용 → 다음 직업 (클릭당 금액 ↑↑)
        ↓
재벌 회장의 "글로벌 지주회사" 구매 → 엔딩
```

### 돈 버는 규칙
| 항목 | 규칙 |
|---|---|
| 직업 전환 | 한 번 도달한 직업은 위쪽 직업 버튼으로 언제든 돌아갈 수 있음 (전직은 가장 높은 직업에서만) |
| 오토클릭 모드 | 스위치로 ON/OFF |
| 방치 보상 | 앱을 꺼도 오토 수익의 50%가 최대 8시간까지 쌓임 |

### 1. 🛵 배달원: 클릭 1회 = 배달 1건 = 4,000원
탈것은 **오토 배달 속도만** 바꿉니다. 산 탈것은 겹치지 않고 **하나를 골라 타며**, 그래서 상위 탈것일수록 속도 가중치가 큽니다.
한 단계 오를 때마다 오토 배달 속도가 **거의 2배**라 탈것을 바꾸면 체감이 큽니다.
가진 탈것은 언제든 바꿔 탈 수 있고, **구매가의 70%에 되팔 수** 있습니다 (도보 제외). 팔아도 다음 탈것 해금은 유지됩니다.
가격은 국내 신차가 기준입니다.

| 탈것 | 가격 | 오토 배달 | 사고 위험 (비, 초당) |
|---|---|---|---|
| 🚶 도보 배달 | 기본 | 0.5건/초 | 없음 |
| 🚲 자전거 | 30만원 | 1건/초 | 1.5% |
| CITI 100 | 210만원 | 2건/초 | 1.2% |
| PCX | 472만원 (2025 공식가) | 3.8건/초 | 0.9% |
| NMAX 155 | 500만원 | 7건/초 | 0.7% |
| XMAX 300 | 890만원 | 13건/초 | 0.5% |
| TMAX 650 | 1,800만원 | 24건/초 | 0.3% |
| R3 | 750만원 | 44건/초 | 0.15% |
| R1000 | 2,800만원 | 80건/초 | 0.05% |

**날씨 피버타임**
| 날씨 | 확률 | 지속 | 배달 1건 | 슬립 (-12만원) | 사고 (-50만원) |
|---|---|---|---|---|---|
| ☀️ 맑음 | - | - | 4,000원 | 없음 | 없음 |
| 🌧️ 우천 | 평균 3분에 한 번 | 30초 | 10,000원 | 초당 2% | 탈것별 위 표 |
| ❄️ 설천 | 평균 10분에 한 번 | 20초 | 20,000원 | 초당 4% | 위 표의 2배 |

비/눈이 오면 화면에 비·눈이 내리고 상단이 어두운 파랑으로 바뀝니다.
슬립·사고는 배달 중일 때(오토 ON이거나 2초 안에 손으로 누름)만 나고, 가진 돈보다 많이 깎이지 않습니다.

NMAX125 공식가(468만원) 외의 XMAX·TMAX·R3·R1은 국내 공식가를 찾지 못해 유럽·일본 가격을 환산해 추정했습니다.
탈것 그림은 `tools/vehicles.py`가 만듭니다.

전직 조건: R1000 보유 + 2억원

### 2. 🏠 공인중개사: 제한 시간 안에 목표 클릭 → 중개보수
클릭으로 바로 돈을 벌지 않습니다. 계약을 골라 **시간 안에 목표 클릭 수를 채우면** 중개보수를 받습니다.
보수는 법정 상한요율(주택 임대 0.3~0.6%, 매매 0.4~0.7%, 상가·빌딩 0.9%)로 계산하고 양쪽 당사자 몫을 합칩니다.
같은 줄의 앞 계약을 3번 성사시키면 다음 계약이 열리고, 빌라 월세 3회 → 전세, 빌라 전세 3회 → 매매가 열립니다.
오토 ON이면 아이템의 자동 클릭이 계약을 도와주고, 끝나면 같은 계약을 자동으로 반복합니다.

| 계약 | 매물 | 보수 | 목표 |
|---|---|---|---|
| 원룸 월세 | 보증금 1,000만 / 월 60만 | 56만원 | 3초 10회 |
| 빌라 월세 | 보증금 3,000만 / 월 90만 | 72만원 | 5초 20회 |
| 아파트 월세 | 보증금 1억 / 월 200만 | 180만원 | 8초 35회 |
| 상가 월세 | 보증금 2,000만 / 월 150만 | 306만원 | 12초 60회 |
| 빌딩 월세 | 보증금 1억 / 월 500만 | 1,080만원 | 20초 110회 |
| 원룸 전세 | 1억 5,000만 | 90만원 | 6초 30회 |
| 빌라 전세 | 2억 5,000만 | 150만원 | 8초 45회 |
| 아파트 전세 | 5억 | 300만원 | 12초 70회 |
| 상가 전세 | 7억 | 1,260만원 | 15초 90회 |
| 빌딩 전세 | 20억 | 3,600만원 | 25초 160회 |
| 원룸 매매 | 1억 8,000만 | 160만원 | 8초 50회 |
| 빌라 매매 | 4억 | 320만원 | 10초 70회 |
| 아파트 매매 | 15억 | 2,100만원 | 15초 110회 |
| 상가 매매 | 30억 | 5,400만원 | 22초 165회 |
| 빌딩 매매 | 100억 | 1억 8,000만원 | 30초 240회 |

아이템(자동 클릭, 비쌀수록 효과가 더 큼): 📄 전단지(기본) +1 · 📱 중개 앱 +1 · 🚗 중고 경차 +1.2 · 🏢 상가 사무실 +1.8 · 📺 부동산 유튜브 +2.4 · 👥 중개보조원 +3.2 · 🏬 2호점 +4.2 · 🏗️ 빌딩 전문팀 +5.5 · 🌐 부동산 플랫폼 +7 (회/초)

전직 조건: 부동산 플랫폼 보유 + 50억원

### 3. 🚒 소방기술사: 계약 성사 → 제한 시간 x3 동안 오토 수익 x3
평소엔 클릭형(클릭당 200만원)이고 아이템 9개를 Lv.10까지 강화해 오토 속도를 올립니다.
소방 계약을 **제한 시간 안에 목표 클릭**으로 성사시키면 **제한 시간의 3배 동안 오토 수익이 3배**가 됩니다.
계약을 이어서 성사시키면 시간이 쌓이고(최대 10분), 계약 클릭은 손으로만 셉니다. 앞 계약 3회 성사 시 다음 계약이 열립니다.

| 계약 | 목표 | 성공 시 x3 시간 |
|---|---|---|
| 🏠 주택 감지기 점검 | 3초 8회 | 9초 |
| 🏪 상가 소방점검 | 5초 22회 | 15초 |
| 🏢 오피스 정밀점검 | 8초 40회 | 24초 |
| 🏬 아파트 단지 점검 | 12초 65회 | 36초 |
| 🏭 공장 소방설계 | 16초 95회 | 48초 |
| 🏥 병원 성능위주설계 | 21초 135회 | 63초 |
| 🏙️ 초고층 빌딩 감리 | 26초 180회 | 78초 |
| ✈️ 공항 소방감리 | 32초 240회 | 96초 |

### 4~5. 🛍️ 쇼핑몰 CEO → 👑 재벌 회장
클릭형 직업. 직업마다 9개 아이템을 최대 Lv.10까지 강화해 오토 속도를 올립니다.
재벌 회장의 "글로벌 지주회사"를 사면 엔딩입니다.

### 예상 플레이 시간 (시뮬레이션)
초당 3~5번 탭하는 경우 (`tools/Simulate.java`):

| 구간 | 걸리는 시간 |
|---|---|
| 배달원 | 약 20분 |
| 공인중개사 | 약 15분 |
| 소방기술사 | 약 40분 |
| 쇼핑몰 CEO | 약 1시간 25분 |
| 재벌 회장 → 엔딩 | 약 1시간 40분 |

밸런스는 `GameData.java` 한 곳에서 조절합니다.

## 프로젝트 구조
```
app/src/main/java/com/shinchang/adventure/
├── MainActivity.java      화면, 탭/오토클릭 효과, 저장
└── game/                  안드로이드와 무관한 순수 게임 로직
    ├── GameData.java      직업·아이템 정의와 밸런스 수치
    ├── GameState.java     돈, 구매, 계약, 전직·직업 전환, 방치 보상, 저장
    ├── Brokerage.java     부동산 중개보수 상한요율 계산
    └── Money.java         "12억 3,400만원" 한국식 금액 표시
tools/Simulate.java        밸런스 시뮬레이터
tools/vehicles.py          탈것 그림(VectorDrawable) 생성기
```
외부 라이브러리 없이 안드로이드 기본 기능만 씁니다 (minSdk 24 = 안드로이드 7.0 이상).

## 빌드 방법
**Android Studio**: 이 폴더를 열고 ▶ Run 을 누르면 폰/에뮬레이터에 바로 설치됩니다.

**명령어**:
```bash
./gradlew assembleDebug
# 결과물: app/build/outputs/apk/debug/app-debug.apk
```

**밸런스 시뮬레이션** (안드로이드 SDK 필요 없음):
```bash
javac -encoding UTF-8 -d out app/src/main/java/com/shinchang/adventure/game/*.java tools/Simulate.java
java -cp out Simulate 3     # 숫자 = 초당 탭 횟수
```
