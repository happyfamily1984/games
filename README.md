# 신창의 모험 🛵 → 👑

배달원으로 시작해서 재벌이 되는 **안드로이드 방치형 클리커 게임**입니다.

## 밑그림 (게임 설계)

### 핵심 루프
```
탭(수동 클릭) / 오토클릭으로 돈 벌기
        ↓
아이템 구매·강화 → 오토클릭 속도 ↑
        ↓
마지막 아이템 + 전직 비용 → 다음 직업 (클릭당 금액 ↑↑)
        ↓
재벌 회장의 "글로벌 지주회사" 구매 → 엔딩
```

### 돈 버는 규칙
| 항목 | 규칙 |
|---|---|
| 오토클릭 1회 | 현재 직업의 **클릭당 금액** |
| 손 클릭 1회 | 클릭당 금액 × (1 + 오토 속도 × 10%) : 손으로 누르면 보너스 |
| 오토클릭 속도 | 산 아이템 레벨의 합. **이전 직업 아이템도 계속 효과가 있음** |
| 오토클릭 모드 | 스위치로 ON/OFF |
| 방치 보상 | 앱을 꺼도 오토 수익의 50%가 최대 8시간까지 쌓임 |

### 직업 (클릭당 금액)
| Lv | 직업 | 클릭당 | 전직 비용 |
|---|---|---|---|
| 1 | 🛵 배달원 | 100원 | 500만원 |
| 2 | 🏠 공인중개사 | 4,000원 | 10억원 |
| 3 | 🚒 소방기술사 | 15만원 | 800억원 |
| 4 | 🛍️ 쇼핑몰 사장 | 600만원 | 6조원 |
| 5 | 👑 재벌 회장 | 2억 5,000만원 | 최종 직업 |

전직 조건: 현재 직업의 **마지막 아이템 보유** + **전직 비용** 지불

### 아이템 (직업마다 9개, 각 최대 Lv.10)
앞 아이템을 1개 이상 사야 다음 아이템이 열립니다. 강화할 때마다 가격이 1.15배 오릅니다.
뒤로 갈수록 비싸지만 속도가 2배씩 빨라집니다 (0.5 → 1 → 2 → … → 128회/초).

| 🚲 자전거 | 📱 중개 앱 등록 | 🧯 점검 장비 | 📸 촬영 스튜디오 | 🛩️ 전용기 |

### 예상 플레이 시간 (시뮬레이션)
초당 3번 탭하면서 효율 좋은 아이템을 사는 경우 (`tools/Simulate.java`):

| 구간 | 걸리는 시간 |
|---|---|
| 배달원 → 공인중개사 | 약 32분 |
| 공인중개사 → 소방기술사 | 약 32분 |
| 소방기술사 → 쇼핑몰 사장 | 약 1시간 6분 |
| 쇼핑몰 사장 → 재벌 회장 | 약 1시간 56분 |
| 재벌 회장 → 엔딩 | 약 4시간 25분 |

총 8시간 30분 정도 플레이하면 엔딩입니다. 방치 보상이 있어서 실제로는 며칠에 걸쳐 즐기게 됩니다.
밸런스는 `GameData.java` 한 곳에서 조절합니다.

## 프로젝트 구조
```
app/src/main/java/com/shinchang/adventure/
├── MainActivity.java      화면, 탭/오토클릭 효과, 저장
└── game/                  안드로이드와 무관한 순수 게임 로직
    ├── GameData.java      직업·아이템 정의와 밸런스 수치
    ├── GameState.java     돈, 구매, 전직, 방치 보상, 저장/불러오기
    └── Money.java         "12억 3,400만원" 한국식 금액 표시
tools/Simulate.java        밸런스 시뮬레이터
```
외부 라이브러리 없이 안드로이드 기본 기능만 씁니다 (minSdk 24 = 안드로이드 7.0 이상).

## 빌드 방법
**Android Studio**: 이 폴더를 열고 ▶ Run 을 누르면 폰/에뮬레이터에 바로 설치됩니다.

**명령어**:
```bash
./gradlew assembleDebug
# 결과물: app/build/outputs/apk/debug/app-debug.apk
```

**밸런스 시뮬레이션** (안드로이드 SDK 필요 없음):
```bash
javac -encoding UTF-8 -d out app/src/main/java/com/shinchang/adventure/game/*.java tools/Simulate.java
java -cp out Simulate 3     # 숫자 = 초당 탭 횟수
```
